Forgot password?
Since this system runs entirely offline, passwords can't be reset by email. Whoever has access to this server computer can reset the Admin password directly:
  1. Close this program if it's running.
  2. Open a Command Prompt in the install folder.
  3. Run: python okv_ims_lan.py --reset-admin
  4. Follow the prompts to set a new password, then start the server again.
For a staff account (not Admin), ask your Admin to reset it from Team & Access.
