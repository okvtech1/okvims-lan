# Public website: OKV IMS LAN Edition

Pages: index.html (home), pricing.html (prices, download buttons, payment-proof form), demo.html (interactive demo), privacy-policy.html, terms.html, cookie-policy.html.

## Where to host it

Upload every file in this folder to **www.okvtechnology.com/okvinms/**. The folder name matters: the get-started QR code, the pricing link inside the LAN app, and the brochure all use `/okvinms/`.

## Before publishing

1. In **pricing.html**, set `LICENSING_API_URL`, `DOWNLOAD_LINKS.windows` and `DOWNLOAD_LINKS.mac`. Search the file for `PASTE_YOUR`. Details: 05-Configuration/CONFIGURATION.md.
2. Do not upload admin.html. It is in 06-Internal-Admin and must stay private.
3. Check the page on a phone. The layout was tested at 320, 360, 390, 414, 600, 768, 1024, 1280 and 1920 pixels wide.

## Until the placeholders are set

The pricing page shows a clear "being set up" message on the payment and download steps. Everything else on the site works.
